## Colores
El diseño respeta los colores representativos del Club de Leones:
- **Amarillo**: `#FFD700`

---

## Tecnologías utilizadas
- **HTML5** → estructura de la página.  
- **CSS3** → estilos personalizados.  
- **Bootstrap 5.3** → componentes y sistema de grid para diseño responsivo.  

---

## Componentes principales
- **Navbar (Bootstrap)** → navegación principal entre páginas.  
- **Hero section** → título, eslogan y mensaje inicial.  
- **Tarjetas (cards de Bootstrap)** → usadas para presentar misión, actividades y secciones de información.  
- **Aside con logo e información rápida** → dirección, horarios y botones de acción.  
- **Footer** → información de derechos reservados.
